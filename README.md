# 题见 PageWise

**让网页题目，一眼有解。**

一款 Chrome AI 题目解析插件：读取整页文字或识别当前屏幕，在浏览器侧栏生成参考答案与解析。企业培训、知识测验、日常练习，都可以省去逐题截图、切换窗口和反复粘贴的操作。

> 打开网页 → 读取题目 → 核对内容 → 查看答案与解析。

## 为什么用题见

- **整页读取**：一次提取页面正文，支持先选中一道题及其选项再读取。
- **一键识图**：直接截取当前可见页面，交给支持视觉的模型识别。
- **侧栏解析**：题目留在网页上，答案与思路显示在旁边。
- **资料辅助**：粘贴培训材料，让模型优先依据你提供的内容回答。
- **模型自选**：连接兼容 Chat Completions 的服务，也支持公司模型网关和本机服务。
- **按需授权**：逐个授权需要读取的网站，点击发送后才向所配置接口提交内容。

## 三分钟开始

1. 下载仓库 ZIP 并解压，或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 回到目标网页，点击工具栏的 **题见 PageWise** 图标。
5. 在“模型设置”填写完整接口地址、模型名称和 API Key，保存并授权接口。
6. 点击“授权当前网站读取”，再点击“读取当前页文字”；图片题可选择“识别可见页面”。
7. 核对文字或截图，按需补充参考资料，点击“发送并生成答案”。

接口地址需要是完整的 Chat Completions 地址，例如 `https://your-model-service.example/v1/chat/completions`。具体模型名称以所用服务为准；截图解析需要视觉模型。Chrome 版本需为 116 或更高。

## 数据如何处理

读取文字和截图在本机进行。点击“发送并生成答案”后，题目、参考资料和所选截图会发送到你配置的模型接口，没有项目自建的中转服务。API Key 保存在本机 Chrome 存储中，不同步，但未加密。请在发送前核对内容，遵守所用平台的规则及公司的信息管理要求。

## 当前边界

- 提供参考答案和解析，不自动选择选项或提交。
- 截图仅覆盖当前可见区域，不会自动滚动截取长页面。
- 跨域内嵌页面、特殊控件可能无法直接读取，可尝试图片模式。
- 读取文字最多 60000 字符；长页面可选中内容或分批处理。
- 当前版本不联网检索。涉及内部制度、最新政策或缺少选项时，应结合培训资料核对。
